# 🎲 DevSorteio — Gerador de Números Aleatórios

Projeto simples feito com **HTML, CSS e JavaScript** puro: você informa um número mínimo e um máximo, clica em **Sortear!** e o site mostra um número aleatório dentro desse intervalo.

🔗 **Teste online:** https://caiocolt.github.io/generator-random/

## 🚀 Tecnologias

- HTML5
- CSS3 (Flexbox, fonte Roboto do Google Fonts)
- JavaScript (DOM, eventos e `Math.random()`)

## 📂 Estrutura

```
├── index.html     # Estrutura da página
├── sorteio.css    # Estilos
├── sorteador.js   # Lógica do sorteio
└── assets/
    └── sort 1.png # Imagem do dado
```

## ▶️ Como usar

1. Clone o repositório:
   ```bash
   git clone https://github.com/caiocolt/generator-random.git
   ```
2. Abra o arquivo `index.html` no navegador.
3. Digite o número inicial e o final e clique em **Sortear!**
